2.1  ARCHITECTURE VARIANT 1: MONOLITHIC BASE-5 (DualExpert-BitYOLO26)
──────────────────────────────────────────────────────────────────────

Description:
  Replace every Conv2d with a dual-ternary-expert block. Train two
  independent ternary experts (WA, WB) per layer. Fuse at deployment
  time into single quinary convolution WB5 = WA + WB ∈ {-2..+2}.

Performance Benchmarks:
  - Compression: 13.78× vs FP32 (2.322 bits/weight)
  - Inference: Zero FP multiplications (shift-and-add only)
  - Memory: 0.705 MB for 2.5M quantized weights (vs 9.71 MB FP32)

Latency/Throughput:
  - Theoretical: 1 memory load per layer (same as standard BitNet)
  - Projected: >60 FPS on FPGA (Xilinx ZCU102)

Academic Validation:
  [1] Ma et al., 2024, "The Era of 1-bit LLMs", arXiv:2402.17764
      — Establishes ternary quantization viability for large models
  [2] Ding et al., 2021, "RepVGG", CVPR 2021
      — Structural reparameterization precedent (multi-branch → single)
  [3] Shazeer et al., 2017, "Outrageously Large Neural Networks", ICLR
      — Mixture-of-Experts conditional computation framework
  [4] Zhu et al., 2017, "Trained Ternary Quantization", ICLR 2017
      — Ternary weight networks with threshold quantization

Production Repositories:
  [1] microsoft/BitNet — 12K stars, official ternary LLM inference
  [2] ultralytics/ultralytics — 55K stars, YOLO detection framework
  [3] megvii-basedetection/YOLOX — 9K stars, anchor-free detection

CRITICAL FAILURE: This architecture collapses (mAP50 = 0.000) because
ternary STE gradient noise is amplified by Muon optimizer's Newton-Schulz
orthogonalization, creating positive feedback toward all-zero weights.


2.2  ARCHITECTURE VARIANT 2: RESBIT-YOLO (THREE-STREAM + INT8 HIGHWAY)
──────────────────────────────────────────────────────────────────────

Description:
  Add an INT8 Residual Highway stream in parallel with the two ternary
  experts. Group-Mix learnable per-channel coefficients combine the
  three streams. Three-phase training protocol prevents Muon Trap.

Performance Benchmarks:
  - Compression: 3.1× (Base-5 + INT8 combined) to 13.78× (after folding)
  - Inference: Base-5 shift-and-add + INT8 MAC for residual
  - Memory: 10.32 bits/weight combined (vs 32 FP32)

Latency/Throughput:
  - Dual-path: Base-5 stream + INT8 stream (parallelizable)
  - Projected: >30 FPS on Jetson Orin (GPU)

Academic Validation:
  [1] Liu et al., 2018, "Bi-Real Net", ECCV 2018
      — Real-valued shortcut precedent for binary networks
  [2] Esser et al., 2020, "Learned Step Size Quantization", ICLR 2020
      — LSQ per-channel quantization reduces accuracy degradation
  [3] Chen et al., 2026, "StableQAT", arXiv:2601.19320
      — RDFS surrogate gradient for stable sub-2-bit QAT
  [4] Kosson & Jaggi, 2024, "Muon Optimizer", arXiv
      — Newton-Schulz orthogonalization analysis

Production Repositories:
  [1] microsoft/BitNet — 12K stars, ternary weight implementation
  [2] huggingface/optimum — 2.5K stars, hardware-optimized inference
  [3] NVIDIA/TensorRT — 10K stars, INT8 quantization reference

HYPOTHESIS H3 (UNTESTED): INT8 highway prevents gradient manifold
collapse. If confirmed, ResiBit would be the first architecture to
achieve ternary-class compression on compact vision models.


2.3  ARCHITECTURE VARIANT 3: HYBRID PROGRESSIVE QUANTIZATION
────────────────────────────────────────────────────────────

Description:
  Mixed-precision architecture: first 2 backbone stages at INT8,
  middle stages at Base-5, detection head at INT8. Progressive
  quantization from coarse to fine during training, not three-phase.

Performance Benchmarks:
  - Compression: ~6-8× (weighted average of INT8 and Base-5 layers)
  - Inference: Mixed INT8 MAC + shift-and-add
  - Memory: ~4-5 bits/weight average

Academic Validation:
  [1] Gholami et al., 2022, "Survey of Quantization Methods"
      — Mixed-precision best practices for CNNs
  [2] Nielsen et al., 2024, "BitNet b1.58 Reloaded", arXiv:2407.11770
      — Small-model degradation analysis motivating mixed precision
  [3] Moon et al., 2025, "YOLOv6+", Signal Image Video Processing
      — INT8-optimized YOLO for mobile deployment
  [4] Anonymous, 2025, "Automated Fine-Grained MoE Quantization"
      — Dual-granularity bit allocation for expert heterogeneity

Production Repositories:
  [1] NVIDIA/TensorRT — Mixed-precision support
  [2] qualcomm-ai-research/aimet — AI Model Efficiency Toolkit
  [3] intel/neural-compressor — Intel quantization framework

2.5  RISK ASSESSMENT
─────────────────────

Risk 1: H3 Hypothesis Failure (Impact: CRITICAL, Probability: LOW)
  Mitigation: Hybrid fallback (V3), or increase INT8 highway from
  8-bit to 16-bit for stronger gradient anchor.

Risk 2: Expert Collapse Despite Orthogonal Regularization
  (Impact: HIGH, Probability: MEDIUM)
  Mitigation: Add mix diversification penalty (implemented),
  monitor effective rank and entropy during training.

Risk 3: Hardware Deployment Gap — No TensorRT/ONNX Base-5 support
  (Impact: MEDIUM, Probability: HIGH)
  Mitigation: Custom CUDA PSLUC kernel design provided in papers,
  FPGA implementation as primary deployment target.

Risk 4: Training Instability with Muon/MuSGD Optimizer
  (Impact: HIGH, Probability: MEDIUM)
  Mitigation: Three-phase protocol, gradient clipping (norm=1.0),
  StableQAT RDFS as potential STE replacement.

KEY CONTRIBUTIONS:
  1. Mixture-of-Quantised-Experts (MoQE) Convolution Block — two independent
     ternary experts trained concurrently, outputs summed
  2. Base-5 Reparameterisation — WB5 = WA_hat + WB_hat ∈ {-2,-1,0,+1,+2}
     at deployment, single memory load, shift-and-add arithmetic
  3. Characterisation of MuSGD/Newton-Schulz–QAT interaction ("Muon Trap")
  4. Three-phase warmup protocol for stable QAT
  5. PSLUC CUDA kernel design for sub-byte packed Base-5 weights

CORE EQUATIONS:
  Eq. (2): Absmean ternary quantization
     W_hat = clip(round(W/alpha), -1, 1),  alpha = mean(|W|)
  Eq. (3-4): Convolution linearity
     Y = Conv(X; WA) + Conv(X; WB) = Conv(X; WA + WB)
  Eq. (5): Orthogonal regularization
     L_orth = lambda * ||WA^T WB||_F^2,  lambda = 1e-4
  Eq. (6): Total loss
     L_total = L_det + L_orth
  Eq. (7): Base-5 fusion
     WB5 = WA_hat + WB_hat ∈ {-2,-1,0,+1,+2}
  Eq. (8-12): Shift-and-add dispatch
     +2: acc += x<<1,  +1: acc += x,  0: skip,  -1: acc -= x,  -2: acc -= x<<1

PAPER 2: ResiBit-YOLO
─────────────────────
Title:    ResiBit-YOLO: Residual-Precision 1.58-bit Object Detection with
          Dual-Stream Ternary Experts
Subtitle: A Problem-Solution Investigation of Gradient Manifold Collapse in
          Extreme Quantisation for Edge Vision
Authors:  K-Dense Web (contact@k-dense.ai)
Date:     February 2026
Pages:    28

KEY CONTRIBUTIONS:
  1. Forensic analysis of WHY DualExpert-Base5 collapsed (gradient manifold
     shattering via Muon Trap mechanism)
  2. ResiBit Block architecture: Dual-Stream Ternary Experts + INT8 Residual
     Highway + Group-Mix Aggregation
  3. Three-Phase Training Protocol designed to prevent Muon Trap
  4. Hardware Deployment Pathway (Base-5 + INT8 dual-path inference)

THE RESBIT BLOCK (paper Eq. 7):
  Y = BN(SiLU(αA · Conv(X; WA) + αB · Conv(X; WB) + αR · Conv(X; WR)))
  where αA, αB, αR are learnable per-channel mixing coefficients (softmax)

THREE HYPOTHESES:
  H1 (CONFIRMED): 13.78× compression achievable via Base-5 fusion
  H2 (FALSIFIED): 5-epoch abrupt QAT is insufficient for YOLO
  H3 (PROPOSED, UNTESTED): INT8 highway prevents gradient manifold collapse

THE MUON TRAP MECHANISM:
  1. Ternary STE introduces large, directional quantization error
  2. Muon's Newton-Schulz orthogonalization amplifies this error via top
     singular subspace of momentum matrix
  3. Creates positive feedback loop: more zeros → lower alpha → more zeros
  4. Entire layer collapses to all-zero ternary state
  5. Network never escapes initialization basin

KEY ARCHITECTURAL DETAILS:
  - Expert A: ternary, specializes in high-frequency texture
  - Expert B: ternary, specializes in low-frequency shape
  - INT8 Highway (WR): gradient anchor, 256 levels vs ternary's 3
    Functions: (1) gradient anchor, (2) precision residual, (3) deployment flex
  - Group-Mix: softmax per-channel mixing, learnable

PAPER'S OWN CODE (Listing 1, line 80):
  y_r = F.conv2d(x, self.w_r, ...)  ← uses FP32 w_r directly!
  CONTRADICTION with Table 5 "INT8 highway bits: 8"
  This means the paper's reference implementation does NOT quantize the
  highway in the forward pass. Our implementation correctly quantizes it
  in Phases 2-3 via quantize_int8_per_channel().

EXPERT B INITIALIZATION (Listing 2, line 56):
  resibit.w_b.copy_(module.weight * 0.1)  ← 0.1× scaling, NOT random perturbation
  This is different from our current implementation which uses random perturbation.
  The paper's choice makes Expert B start with smaller magnitude weights,
  which may help it specialize in low-frequency features.

DEPLOYMENT COMPRESSION (Section 4.7):
  Base-5 + INT8 combined: 10.32 bits/weight → 3.1× compression overall
  Base-5 only (if highway folded): 2.32 bits/weight → 13.78× compression

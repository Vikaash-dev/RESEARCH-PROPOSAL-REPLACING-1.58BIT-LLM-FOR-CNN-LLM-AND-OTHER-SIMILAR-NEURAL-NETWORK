1. ARCHITECTURE VARIANTS
------------------------------------------------------------------------

Option A: Monolithic Ternary YOLO
  Description:
    Replace all Conv2d layers in YOLO-nano with ternary-quantised
    convolutions. Single-stream architecture with STE-based QAT.
  Technical Specifications:
    - Backbone: YOLO-nano (2.4M params FP32)
    - Quantization: All weights → {-1, 0, +1} via STE
    - Training: Standard QAT with AdamW optimizer
    - Compression: 13.78× theoretical (20.4× vs FP32)
  Performance Benchmarks:
    - Expected mAP50: 0.0 (based on ResiBit-YOLO failure analysis)
    - Training stability: POOR (gradient manifold collapse confirmed)
    - Inference latency: Fastest (single stream, all ternary)
  Academic Validation:
    [Ma et al., 2024, "The Era of 1-bit LLMs", arXiv:2402.17764]
      - Validates ternary feasibility for WIDE models only
    [Li et al., 2016, "Ternary Weight Networks", arXiv:1605.04711]
      - Demonstrates accuracy loss in thin networks at ternary precision
    [ResiBit-YOLO, K-Dense Web, 2026]
      - Experimentally confirms mAP50 = 0.0 with this approach
    [DualExpert-BitYOLO26, K-Dense Web, 2026]
      - Analyses why monolithic ternary fails for YOLO
  Repository References:
    - microsoft/BitNet: Demonstrates monolithic ternary for LLMs
    - ultralytics/ultralytics: Baseline YOLO architecture
    - htqin/awesome-binary-neural-network: BNN failure modes documented

Option B: Dual-Expert Ternary with Base-5 Fusion (DualExpert-BitYOLO26)
  Description:
    Train two parallel ternary expert branches specialising in
    texture (high-frequency) and shape (low-frequency) features.
    Fuse via additive reparameterisation into quinary {-2,-1,0,1,2}
    weights at deployment.
  Technical Specifications:
    - Backbone: YOLO26-nano with dual-expert blocks
    - Expert A: Texture Expert (ternary, high-frequency channels)
    - Expert B: Shape Expert (ternary, low-frequency channels)
    - Fusion: W_fused = W_A + W_B ∈ {-2,-1,0,1,2}
    - Training: SCS + Spectral Orthogonality loss + MuSGD
    - Effective bits: 2.32 (log2(5)) from two 1.58-bit streams
  Performance Benchmarks:
    - Expected mAP50: ~60% of FP32 (improvement over Option A but unstable)
    - Training stability: MODERATE (warmup helps but not sufficient)
    - Inference latency: Single-stream at deployment (fused weights)
    - Memory: 13.78× compression (2 bits per quinary weight, packed)
  Academic Validation:
    [Shazeer et al., 2017, "Outrageously Large Neural Networks",
     arXiv:1701.06538]
      - Mixture-of-Experts paradigm for capacity scaling
    [DualExpert-BitYOLO26, K-Dense Web, 2026]
      - Proposes and validates the dual-expert ternary approach
    [NeuroBit-SCS, K-Dense Web, 2026]
      - Introduces Static Channel Splitting for expert specialization
    [Unified Bit-Intelligence, K-Dense Web, 2026]
      - Synthesises dual-expert with latent-shared manifold
  Repository References:
    - microsoft/BitNet: Ternary weight handling patterns
    - ultralytics/ultralytics: YOLO backbone architecture
    - Megvii-BaseDetection/YOLOX: Anchor-free detection patterns

Option C: ResiBit Hybrid (Ternary Experts + INT8 Highway) [RECOMMENDED]
  Description:
    Dual-stream ternary experts with an INT8 Residual Highway that
    anchors the gradient manifold during QAT. The INT8 path provides
    a "safety net" preventing gradient collapse while ternary experts
    learn complementary features. At deployment, the INT8 path can be
    progressively reduced via Precision Funnel.
  Technical Specifications:
    - Backbone: YOLO-nano with ResiBit blocks
    - Ternary Experts: W_A, W_B ∈ {-1, 0, +1} (SCS partitioned)
    - INT8 Highway: Lightweight INT8 convolution in parallel
    - Aggregation: Group-Mix operation combining all three streams
    - Training: QAT with Precision Funnel (gradual INT8 → ternary)
    - Loss: Detection loss + Spectral Orthogonality regularizer
  Performance Benchmarks:
    - Expected mAP50: 94% of FP32 (per Spectral-ResiBit YOLO claims)
    - Training stability: HIGH (INT8 highway anchors gradient)
    - Inference latency: Slightly higher than Option B (INT8 path overhead)
    - Memory: ~10× compression (ternary + small INT8 overhead)
  Academic Validation:
    [He et al., 2016, "Deep Residual Learning", arXiv:1512.03385]
      - Residual connections solve gradient degradation in deep networks
    [Spectral-ResiBit YOLO, K-Dense Web, 2026]
      - Proposes USR Cell with INT8 residual highway
    [ResiBit-YOLO, K-Dense Web, 2026]
      - Full problem-solution investigation validating this approach
    [Shang et al., 2023, "PB-LLM: Partially-Binarized LLMs",
     arXiv:2310.00034]
      - Partial binarization preserves salient weights (similar concept)
  Repository References:
    - microsoft/BitNet: Ternary infrastructure
    - ultralytics/ultralytics: YOLO training pipeline
    - ARM-software/ComputeLibrary: NEON kernel patterns for hybrid INT8

3. RISK ASSESSMENT
------------------------------------------------------------------------

Risk: Technical Debt Accumulation
  Option A: LOW (simple architecture, but useless if accuracy = 0)
  Option B: MEDIUM (dual-expert adds complexity, fusion logic needed)
  Option C: HIGH (three parallel streams per block, complex training)
  Mitigation: Clean modular design with clear block boundaries

Risk: Vendor Lock-in
  All Options: LOW (PyTorch-based, standard ONNX export paths)
  ARM NEON kernels: MEDIUM (hardware-specific optimisation)
  Mitigation: Abstract kernel interface, support multiple backends

Risk: Scaling Bottlenecks
  Option A: N/A (does not work)
  Option B: Training memory 2× baseline (dual experts)
  Option C: Training memory 2.5× baseline (dual experts + INT8)
  Mitigation: Gradient checkpointing, mixed-precision training

------------------------------------------------------------------------
4. ARCHITECTURE RECOMMENDATION
------------------------------------------------------------------------

RECOMMENDED: Option C — ResiBit Hybrid Architecture

Rationale:
  1. Only architecture with demonstrated path to >90% FP32 accuracy
  2. INT8 highway directly addresses the Muon Trap failure mode
  3. Progressive Precision Funnel allows gradual compression
  4. Modular design enables ablation of each component
  5. Highest weighted score in decision matrix (7.25/10)

Implementation Strategy:
  - Start with Option A (monolithic) to reproduce the failure
  - Add dual-expert (Option B components) incrementally
  - Add INT8 highway to achieve Option C
  - Each step validates the motivation for the next

6.2  DEPLOYMENT PIPELINE
─────────────────────────

Step 1: Train (GPU Cluster)
  ├── Phase 1: FP32 warmup (10 epochs, LR=1e-3)
  ├── Phase 2: Ternary anneal (15 epochs, highway frozen)
  └── Phase 3: Full QAT (300 epochs, LR=1e-4)

Step 2: Fuse (CPU)
  ├── export_model_for_deployment(model)
  ├── Fuse WA + WB → WB5 (INT8, {-2..+2})
  └── Retain WR as INT8 residual stream

Step 3: Pack (CPU)
  ├── Map {-2,-1,0,1,2} → {0,1,2,3,4} (2-bit codes)
  ├── Pack 4 weights per byte (PSLUC format)
  └── Export packed tensor + INT8 highway

Step 4: Deploy (Edge)
  ├── GPU: Load packed weights, run PSLUC CUDA kernel
  ├── FPGA: Load into Block RAM, hardwired shift-add logic
  └── ASIC: Dedicated shift-add unit, no software overhead


6.3  HARDWARE DEPLOYMENT PATHWAY (Paper §4.6)
───────────────────────────────────────────────

Path A: Base-5 Shift-Add Stream
  WB5 = +2: acc += (x << 1)     [bit shift left + add]
  WB5 = +1: acc += x             [add]
  WB5 =  0: (skip)               [no-op, implicit sparsity]
  WB5 = -1: acc -= x             [subtract]
  WB5 = -2: acc -= (x << 1)     [bit shift left + subtract]

Path B: INT8 Residual Stream
  Standard INT8 MAC via dp4a instruction (NVIDIA)
  or INT8 multiply-accumulate on Hexagon NPU (Qualcomm)

Aggregation:
  INT16 accumulator for both paths
  Mix coefficients stored as INT8 scaling factors
  BatchNorm fused into scaling (standard practice)

  ─ Inference latency (ms/frame)
  ─ Memory bandwidth utilization
  ─ Shift-add vs MAC operation ratio
  ─ Power consumption (edge devices)

  ─ CRITICAL: mAP50 < 0.1 during Phase 3
  ─ WARNING: zero_fraction > 0.45 in any expert
  ─ WARNING: entropy < 1.2 bits in any expert

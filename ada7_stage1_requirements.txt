1.2  COMPETITIVE ANALYSIS — OPEN-SOURCE PROJECTS
──────────────────────────────────────────────────

Project 1: microsoft/BitNet
  GitHub stars: ~12,000 (as of Feb 2026)
  Description: Official Microsoft 1.58-bit LLM implementation
  Strengths: Production-quality, fast CPU inference (2-4× speedup)
  Weakness: LLM-only — no CNN/YOLO support, fails on <3B models
  Gap: No solution for compact vision models
  Citation: [Wang et al., 2023], [Ma et al., 2024]

Project 2: ultralytics/ultralytics (YOLO)
  GitHub stars: ~55,000
  Description: Official YOLO implementation including YOLO26
  Strengths: State-of-the-art detection, comprehensive ecosystem
  Weakness: Only supports INT8/FP16 quantization (TensorRT/ONNX)
  Gap: No sub-4-bit quantization support
  Citation: [Ultralytics Team, 2025]

Project 3: huggingface/optimum
  GitHub stars: ~2,500
  Description: Hardware-optimized inference including quantization
  Strengths: Broad ecosystem, ONNX/TensorRT integration
  Weakness: Minimum 4-bit quantization, no ternary support
  Gap: No shift-and-add inference path

Project 4: mit-han-lab/once-for-all
  GitHub stars: ~1,800
  Description: Neural architecture search with sub-network sampling
  Strengths: Hardware-aware NAS, efficient deployment
  Weakness: Focuses on pruning, not extreme quantization
  Gap: No ternary or Base-5 weight representation

Project 5: htqin/awesome-binary-neural-network
  GitHub stars: ~800
  Description: Curated list of binary/ternary network research
  Strengths: Comprehensive reference, tracks latest advances
  Weakness: Collection only — no unified implementation
  Gap: No single implementation combining dual-expert + Base-5 + INT8 highway

1.4  FEATURE GAP ANALYSIS
───────────────────────────

Evidence from literature and issue trackers:

Gap 1: Ternary QAT collapses on small models (<3B params)
  Evidence: [Nielsen et al., 2024] arXiv:2407.11770 — 5-10% degradation
  Evidence: Our Paper 2 §3 — 100% collapse on 2.4M param YOLO26n
  Reddit: r/MachineLearning threads on "BitNet fails on small models"
  Frequency: High — fundamental limitation of current approaches

Gap 2: No multiplication-free detection model exists
  Evidence: No published mAP result for shift-and-add YOLO inference
  GitHub: Zero repositories with working Base-5 YOLO deployment
  Frequency: Critical unmet need for edge ML community

Gap 3: Gradient collapse during extreme QAT is poorly understood
  Evidence: Paper 2 §3.3 — first formal characterization (Muon Trap)
  Evidence: StableQAT [Chen et al., 2026] addresses partial case
  Frequency: Every attempt at <2-bit YOLO fails without mitigation

Gap 4: No INT8 gradient anchor architecture exists for CNNs
  Evidence: Bi-Real Net [Liu et al., 2018] uses FP32 shortcut (too expensive)
  Evidence: Our Paper 1 proposes ResiBit (INT8 highway) as solution
  Frequency: Novel contribution — first in literature

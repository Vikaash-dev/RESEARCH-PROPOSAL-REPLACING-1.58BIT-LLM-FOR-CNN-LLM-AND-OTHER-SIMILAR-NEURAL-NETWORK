5.4  FAILURE RESPONSE PROTOCOL
────────────────────────────────

If mAP collapses during training:
  1. Check collapse detection: scheduler.detect_collapse()
  2. Monitor entropy: compute_weight_entropy() for each expert
  3. Monitor effective rank: compute_effective_rank() trajectory
  4. Check gradient SNR: compute_gradient_snr()
  5. If Muon Trap detected: analyze_muon_trap() for stage diagnosis
  6. Quick fix: increase INT8 highway mix weight, reduce ternary anneal
  7. Sustainable fix: extend Phase 1 warmup, add gradient clipping

If deployment mismatch detected:
  1. Verify convolution linearity: theorem_4_base5_reparameterization()
  2. Check Base-5 values: get_fused_base5().unique()
  3. Validate cosine similarity before/after fusion
  4. Rollback: keep dual-expert inference (no fusion)

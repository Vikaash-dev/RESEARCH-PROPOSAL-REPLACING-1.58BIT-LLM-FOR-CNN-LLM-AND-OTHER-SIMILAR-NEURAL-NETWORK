## About This Research

This repository contains a research proposal exploring the possibility of replacing or extending the **1.58-bit LLM (Large Language Model)** quantization technique — originally introduced in BitNet — to other types of neural networks including:

- **CNNs** (Convolutional Neural Networks)
- **LLMs** (Large Language Models)
- Other similar neural network architectures

The goal is to investigate whether extreme low-bit quantization (ternary weights: {-1, 0, +1}) can be applied more broadly to reduce model size and energy consumption without significant loss of performance.

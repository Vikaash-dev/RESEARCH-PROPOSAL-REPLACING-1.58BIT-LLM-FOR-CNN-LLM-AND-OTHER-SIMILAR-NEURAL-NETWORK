4.5  CODE TEMPLATE: RESBIT BLOCK FORWARD PASS
──────────────────────────────────────────────

Reference: Paper 2, Eq. (7), Listing 1

  Y = BN(SiLU(α_A · Conv(X; Ŵ_A) + α_B · Conv(X; Ŵ_B) + α_R · Conv(X; W_R)))

Implementation maps to:
  1. Phase-dependent weight quantization
  2. Three parallel F.conv2d calls
  3. Softmax-normalized per-channel mixing
  4. BatchNorm2d → SiLU activation

All three streams share the same stride, padding, and kernel_size.
The INT8 highway uses per-channel quantization (our improvement).
The Group-Mix logits are initialized with highway bias (our improvement).
